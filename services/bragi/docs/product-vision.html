The thesis

One claims-intelligence stack.
Every insurance line. Built once, sold many times.

We don't build a motor product. We build the reusable capabilities a claim needs — capture, document intelligence, verification, image intelligence, fraud, and agentic settlement — then point them at one line after another. Motor is the first composition. Health is the same stack, reconfigured.

What it isSix composable modules + an agent that runs the claim.
Why it winsEach new line reuses the stack; each new module lifts every line.
How it sellsOutcome products on top, capability APIs underneath.

2 · How a claim moves through the stack

Capture → Understand → Verify → Score → Settle

The same pipeline for every line. Only the models and rules in the middle change. The agent at the end is the moat — it turns a set of tools into the system that runs the claim.

Agent acts

The human still decides. Through Phase 1 the stack recommends and explains; it never auto-approves or rejects. Agentic settlement raises how much it can do on its own, line by line, as trust is earned.

3 · How we package & sell it

Land on a capability, expand to the outcome, grow into the agent

Same code, three price points and three stories. Sell the outcome to the business; sell the API to the developer; sell the agent as the future.

Tier 1 · Land

Module APIs

Buyer: developers / digital teams

Buy one capability and wire it in. Proves the composability and gets us in the door.

  • Document Intelligence API
  • Capture API
  • Verification API
Tier 2 · Expand

Vertical Engines

Buyer: claims & investigation teams

A pre-wired bundle for one line, sold as an outcome with a report and a dashboard.

  • Health Claims Engine · next
  • …one per line
Tier 3 · Own the claim

Agentic Settlement

Buyer: claims leadership / COO

The agent runs the end-to-end claim. Highest value, deepest lock-in, the north star.

  • Straight-through for clean claims
  • Investigator-ready for the rest
  • Priced on outcomes
