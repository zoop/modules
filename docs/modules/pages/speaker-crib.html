The hardest likely questions — one-breath answers

"Why build this when vendors exist?" · CTO

We integrate the commodities — OCR, vision/LLM models, workflow engine, model gateway. We build what no vendor sells: the Signal model, the fused image×document checks, and the pack + compliance layer. That composition is the only IP.

"Isn't this a platform before product-market fit?" · CSO

Phase 1 is a product, not a platform — one motor product, end to end. The platform-ness is just disciplined contracts and a CI check. If the product fails, we lost nothing to the platform; if it works, product #2 costs a pack.

"Domain-agnostic — proven?" · Architect

No — design intent. It becomes real the day pack #2 ships with zero engine change (Phase 2). Until then we guard it with the Signal model and a CI check that fails on domain nouns in engine code.

"Is 'agentic' real or fashionable?" · VP Eng

Phase 3, deliberately. The agent's tools are the capability services — they must exist first. Until then, the deterministic DAG does everything we're selling.

"Where do models plug in, and who owns accuracy?" · ML

Everything goes through the Model Gateway (own + third-party, versioned). Review corrections become labels; the eval registry versions models per pack. Designed to publish accuracy — nothing measured in prod today.

"What can I sell first, to whom?" · PM

Single modules self-serve — verification alone, extraction alone, inspection alone — and the composed motor product for insurers. Entitlements make every subset a sellable SKU.

Thin ice — own it before they find it

Do not overclaim tomorrow:
  • No named customers; all data on screen is sample; no published accuracy.
  • Agent Runtime and the cross-tenant link graph are roadmap (Phase 3). The cross-tenant graph also needs legal review — don't promise it.
  • Compliance: ~80% is policy-as-config, but model-region routing and novel obligations are real build work, not a flag.
  • "Domain-agnostic" and "every correction trains the engine" are design intent until Phase 2 proves them.

Junior lifelines — define in passing, don't make it a lecture

Pack — a config bundle that teaches the generic engine one industry; product writes it, engineering doesn't touch the engine.
Signal — a typed note each step leaves on the case; later steps read all the notes instead of calling each other.
DAG — a fixed recipe of steps; deterministic = same input, same path. The Agent Runtime is the alternative where an AI picks the steps.
Fused check — catching what no single source shows, by cross-checking documents against images.
Vahan / RC / IRDAI / DPDP — vehicle registry · registration certificate · insurance regulator · India's data-protection law.
